## Method

DELETE candidates are UI scaffolds with no consumer, not old-looking filenames. alert.tsx has a commented import in builder only. Public URLs may have external users; retain pending owner review. Generated does not mean deletable. Recheck every candidate before any later removal.

## Safe sequence

1. Resolve UNKNOWN provenance and fixture consent.
2. Review tracked test outputs and tooling metadata; exclude old ignored worktrees from lint.
3. Archive superseded plans, preserving links and decisions. EXECUTION.md and files/EXECUTION.md are byte-identical.
4. Recheck and remove only verified UI candidates in a separate change.
5. Remove dependencies only after their last verified consumer; consolidate role maps without changing semantics.
6. Run unit/type/lint/build and targeted E2E regression; update journal.
