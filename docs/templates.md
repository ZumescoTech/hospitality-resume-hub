# Resume Templates Guide

## Template Types

1. Classic Professional
- Clean layout
- Ideal for waiters

2. Modern Minimal
- Simple typography
- Ideal for bartenders

3. Elegant Sommelier
- Premium look
- Focus on wine knowledge

---

## Template Rules
- Must accept JSON data
- Must include profile image
- Must be printable (A4 format)
- Must maintain spacing and alignment

---

## Design Principles
- Strong hierarchy (name > title > sections)
- Consistent spacing
- Readable fonts
